1 Установка

Окружение

Обучение использует GPU через JAX/MJX, поэтому нужен Linux с CUDA. На Windows — WSL2 с Ubuntu.

# в PowerShell, от администратора
wsl --install -d Ubuntu-22.04

Python-окружение

# внутри WSL/Ubuntu
python3 -m venv ~/venvs/mycobot-rl
source ~/venvs/mycobot-rl/bin/activate

pip install --upgrade pip
pip install "jax[cuda12]" torch mujoco mujoco-mjx \
            mujoco_playground rsl-rl-lib matplotlib

Первый импорт mujoco_playground проверяет, скачан ли репозиторий готовых моделей mujoco_menagerie — нашему роботу оттуда ничего не нужно, но папку стоит один раз создать заранее (mkdir -p ~/.cache/mujoco_menagerie или путь, который укажет ошибка), чтобы не ждать загрузки нескольких гигабайт.

Код проекта

git clone <адрес репозитория>
cd <папка проекта>

Проверка GPU

python3 -c "import jax; print(jax.devices())"
# должно показать CudaDevice, не CPU

2 Настройка

Весь конфиг — в config.py, изменения подхватываются и обучением, и просмотром автоматически.

ЧтоГдеПример
Какого робота грузитьENV_NAME ENV_NAME=PandaPickCube python3 teleop.py — эталон вместо своего
Архитектура сетиACTOR_HIDDEN_DIMS, CRITIC_HIDDEN_DIMS[512, 256, 128]
Потолок разброса действийPPO_STD_MAX (переменная окружения)PPO_STD_MAX=1.0
Число эпох/минибатчей PPOPPO_EPOCHS, PPO_MINIBATCHESPPO_EPOCHS=8
Скорость обученияPPO_LRPPO_LR=3e-4

Без потолка разброса действий (PPO_STD_MAX) обучение неустойчиво: разброс действий политики со временем уходит в разнос, и движения становятся слишком резкими для точного захвата. PPO_STD_MAX=1.0 — рабочее значение, использованное для текущего результата.

3 Обучение

Запуск

cd <папка проекта>
source ~/venvs/mycobot-rl/bin/activate

PPO_STD_MAX=1.0 python3 train.py --exp_name champion --max_iters 1150
ФлагСмыслПо умолчанию
--exp_nameимя прогона, папка logs/<имя>по времени запуска
--max_itersсколько итераций обучения1001
--num_envsпараллельных сред симуляции4096 на GPU
--resumeпуть к чекпоинту, чтобы продолжить обучение—
--save_intervalраз в сколько итераций сохранять чекпоинт50

Продолжить обучение

PPO_STD_MAX=1.0 python3 train.py --exp_name champion \
    --resume logs/champion/model_1100.pt --max_iters 500

Следить за прогрессом

Обучение само пишет лог в формате TensorBoard — среднюю награду, потери, разброс действий и т.д. — в logs/<имя>/.

tensorboard --logdir logs/champion --port 6006
# открыть http://localhost:6006 в браузере

4 Как посмотреть на робота

Покрутить руками, без обучения

python3 teleop.py
# откроется окно MuJoCo, слайдеры справа (вкладки Joint/Control)
# двигают суставы напрямую

Посмотреть обученную политику

python3 inference.py --checkpoint results/best/champion.pt --episodes 8

Записать видео

python3 inference.py --checkpoint results/best/champion.pt \
    --episodes 5 --record demo.mp4
